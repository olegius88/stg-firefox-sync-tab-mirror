# STG Sync Tab Mirror (Git 3-Way Merge Engine)

Расширение для **Firefox Developer Edition / Nightly / Release**, обеспечивающее **зеркальную фоновую синхронизацию открытых вкладок, групп Simple Tab Groups (STG) и нативных групп вкладок Firefox** между несколькими компьютерами по принципу **Git (`3-Way Merge: BASE + LOCAL + REMOTE`)** через встроенный движок **Firefox Sync (`browser.storage.sync` + `Weave.Service`)**.

---

## 🔀 Принцип работы: как в Git (`3-Way Merge` + `Mergetool` + `git log`)

Вместо простой перезаписи состояния расширение хранит три снимка (коммита), как полноценная система контроля версий Git:
1. **`BASE` (`baseCommit`)** — последний общий родительский коммит (`#hash`), успешно синхронизированный этим браузером.
2. **`LOCAL` (`Working Tree`)** — текущие открытые вкладки и группы в этом браузере.
3. **`REMOTE` (`HEAD` в Firefox Sync)** — последний коммит в облаке Firefox Sync.

### Как выполняется слияние (`git pull --rebase` + `merge` + `push`):
- **Fast-Forward Pull (`LOCAL == BASE`, `REMOTE != BASE`)**: если вы работаете на ПК 1, а ПК 2 просто открыт в фоне (например, на группе **«Чаты сендапи»**), ПК 2 автоматически применяет дельту коммита из облака. Новая вкладка в группе **«ютюб»** создаётся справа строго **в фоновом режиме (`hidden: true`, `active: false`)**, не переключая активную группу на ПК 2.
- **Автоматическое слияние без конфликтов (`Auto-Merge`)**:
  - Если на ПК 1 открыта вкладка `A`, а на ПК 2 параллельно открыта вкладка `B` — обе вкладки сохраняются и объединяются в общий мерж-коммит (`A + B`).
  - **Полевое авто-слияние (Field-level Merge)**: если для одной и той же вкладки на ПК 1 изменился только URL, а на ПК 2 её переместили в другую группу STG — изменения автоматически сливаются без потерь.
- **Обнаружение и разрешение конфликтов (`Git Mergetool`)**:
  - Конфликт возникает только тогда, когда **одна и та же вкладка одновременно изменена по-разному на двух ПК с момента `BASE`** (например, перешла на два разных URL, перемещена в две разные группы, либо закрыта на одном ПК и изменена на другом).
  - При обнаружении конфликта расширение **не затирает спорную вкладку**, включает индикатор **`⚡N`** на иконке тулбара и открывает встроенный **Mergetool**:
    - **Построчное решение по каждой вкладке**: `Моё (Local)`, `Удалённое (Remote)` или `Обе вкладки (Keep Both)` (сохраняет обе версии рядом в фоне без потерь).
    - **Массовые кнопки**: `Все мои (--ours)`, `Все удалённые (--theirs)`, `Обе версии (Keep Both)`.
- **История коммитов и откат (`git log` / `git reset --hard`)**:
  - Во вкладке **«📜 История коммитов (git log)»** отображаются последние коммиты с хешами (`#a1b2c3d`), автором (именем ПК), временем и описанием изменений (`+added ~modified -deleted`).
  - Напротив каждого коммита есть кнопка **«Откатить»** (`git reset`), восстанавливающая вкладки и группы к выбранному снимку.

## 🚀 Быстрая установка в 1 команду (PowerShell)

На любом компьютере откройте **PowerShell** и выполните:

```powershell
irm https://raw.githubusercontent.com/olegius88/stg-firefox-sync-tab-mirror/main/install.ps1 | iex
```
