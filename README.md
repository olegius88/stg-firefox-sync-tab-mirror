# STG Firefox Sync Tab Mirror

Расширение для **Firefox Developer Edition / Nightly / ESR**, обеспечивающее **зеркальную фоновую синхронизацию открытых вкладок, групп Simple Tab Groups (STG) и нативных групп вкладок Firefox** между несколькими компьютерами через **встроенный движок синхронизации Firefox Sync (`extension-storage` + `Weave.Service`)**.

---

## 🎯 Как работает зеркальный режим

Представим два компьютера с вашим аккаунтом Firefox Sync, где включён зеркальный режим:
- На **Машине 1** вы активно работаете в группе **«ютюб»** и открываете новую вкладку справа.
- На **Машине 2** открыт Firefox (в фоне или вы работаете в нём в другой группе — например, **«Чаты сендапи»**).
- Расширение на **Машине 1** сохраняет дельту в зашифрованное хранилище `browser.storage.sync` (разбивая состояние на чанки) и принудительно вызывает движок синхронизации Firefox `Weave.Service.sync({ engines: ["extension-storage"], why: "user" })`.
- Расширение на **Машине 2** в фоновом режиме принимает обновление из Firefox Sync и через внутренний мост к **Simple Tab Groups (`Tabs.add` / `Groups.load`)** создаёт эту вкладку внутри группы **«ютюб»** справа — **неактивной (`active: false`) и скрытой (`hidden: true`)**, не переключая текущую открытую группу **«Чаты сендапи»** и не сбивая фокус активной вкладки.

### Что синхронизируется:
1. **Открытие новых вкладок** (с сохранением группы STG, позиции внутри группы и нативной группы Firefox).
2. **Закрытие вкладок** (через систему меток удаления `tombstones`; при этом закрытие всего окна браузера при выходе из Firefox игнорируется, чтобы выключение ПК 1 не закрыло вкладки на ПК 2).
3. **Навигация (смена URL)** внутри открытых вкладок.
4. **Перемещение вкладок** между группами Simple Tab Groups и нативными группами Firefox.
5. **Умная дедупликация при старте**: если на обеих машинах уже открыты одинаковые URL в одних и тех же группах STG, расширение связывает их без создания дублей, а недостающие вкладки тихо создаёт в фоне.

## 🚀 Быстрая установка в 1 команду (PowerShell)

На любом компьютере откройте **PowerShell** и выполните:

```powershell
irm https://raw.githubusercontent.com/olegius88/stg-firefox-sync-tab-mirror/main/install.ps1 | iex
```

После выполнения команды перезапустите Firefox.
